# Learning and Formal Methods for Robotics (LAFR)

Website for the **Learning and Formal Methods for Robotics (LAFR)** workshop at **IROS 2026**.

The workshop focuses on two complementary directions:

- **Learning for formal methods**
- **Learning with formal methods**

Date: **October 1, 2026**  
Location: **Pittsburgh, PA**

Website: https://lafr-workshop.github.io/

Organizers: Neel Bhatt, Jason Liu, Xusheng Luo, Yiwei Lyu, Julie Shah, Huy T. Tran, and Lei Zheng.
